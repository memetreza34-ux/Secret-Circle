Datenschutz

Deine Daten bleiben auf deinem Gerät

Secret Circle funktioniert ohne Benutzerkonto, ohne Tracking und ohne eigenen Server.

Welche Daten werden gespeichert?

Die App speichert Spielnamen, Einstellungen, eigene Kategorien, aktive Spielstände und den lokalen Rundenverlauf im Browser-Speicher deines Geräts.

Sicherung exportieren und importieren

Du kannst diese lokalen Daten als JSON-Sicherungsdatei exportieren. Die Datei wird ausschließlich über die Download-Funktion deines Browsers auf deinem Gerät gespeichert. Beim Import wird die ausgewählte Datei lokal geprüft und verarbeitet; ihr Inhalt wird nicht an einen Server von Secret Circle übertragen.

Eine Sicherungsdatei kann Spielernamen, eigene Kategorien, Einstellungen, Verlauf und einen aktiven Spielstand enthalten. Bewahre sie deshalb nur an einem Ort auf, dem du vertraust.

Werden Daten übertragen?

Nein. Die Spielinhalte werden nicht an einen Server des App-Betreibers übertragen. Beim ersten Laden und bei Aktualisierungen ruft dein Browser lediglich die statischen App-Dateien vom Hosting-Anbieter ab.

Offline-Modus

Ein Service Worker speichert notwendige App-Dateien lokal, damit Secret Circle nach dem ersten vollständigen Laden offline genutzt werden kann.

Daten löschen

Alle von Secret Circle gespeicherten Daten können direkt in der App über „Alle lokalen Daten löschen“ entfernt werden. Alternativ kannst du die Website-Daten in den Browser-Einstellungen löschen. Bereits exportierte Sicherungsdateien müssen separat im Dateisystem deines Geräts gelöscht werden.

Analyse und Werbung

Secret Circle verwendet keine Analyse-, Werbe- oder Tracking-Dienste.

Hinweis zur Veröffentlichung

Vor einer öffentlichen kommerziellen Veröffentlichung müssen Verantwortlicher, Kontaktmöglichkeit, Hosting-Anbieter und gegebenenfalls ein vollständiges Impressum ergänzt werden.
